# Comparison images — offscreen evidence

Generated by the freshly compiled `scripts/benchmark-structured-filtering.sh` harness using an APFS clone of the preserved 2,959,505-node catalog. These depict indexed/previously measured storage, not a new filesystem scan. All windows remained offscreen and never ordered in; activation policy was prohibited. They are **not native desktop acceptance screenshots**.

The `explorer-` files render the real explorer panel at 1100×720 points (standard) and 650×430 points (minimum panel), at 2× resolution. The matching files without that prefix render the full explorer page at 1440×900 and 1000×640 points, including Inspector and Navigator. The standalone panel includes its normal selection context; the page puts that context in the Inspector.

Visual review: the panel captures retain the radial structure, depth rings, palette, selected orange outline, size key and rotated label style. Hide keeps the existing positions and leaves genuine gaps; isolation uses its own root scale; selected/path labels remain distinct in the sampled light/dark minimum views. Filters add one compact native control row and an isolation row only when active.

Full-page offscreen AppKit `List`/control bitmaps have black or blank regions, especially below the canvas. Those capture limitations are retained transparently, not presented as faithful native Navigator rendering. Prefer the panel images for visualization comparison. Actual native rendering, physical interaction, focus/transition pacing and accessibility remain pending in `NATIVE-QA-PLAN.md`.
