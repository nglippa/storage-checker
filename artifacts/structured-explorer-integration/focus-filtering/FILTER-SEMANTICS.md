# Filter semantics

1. Choose the current visual root: the browser root, or one active isolation root from the same loaded hierarchy.
2. Evaluate indexed allocated bytes for real nodes. Presets use decimal units: 100 MB = 100,000,000 bytes; 1 GB = 1,000,000,000 bytes. All includes unknown sizes; positive thresholds never treat unknown as zero or substitute logical size. Custom accepts a finite positive decimal value and explicit MB/GB unit within Int64 range; invalid input does not change the active filter.
3. Keep the root, selected node and necessary actual ancestor chains. Root-relative Levels remains the existing depth control. A deeper selected exception uses its real full chain when filtering/focus/isolation is active, without a synthetic shortcut parent.
4. Dim mode retains the laid-out hierarchy; nonmatches use 20% opacity. Required contextual ancestors use 80%. Hide mode removes nonmatching primitives, retaining matching ancestors and selection context. Filtering an already placed selection does not change radial positions or radii. A deep selection exception may add its real parent chain; isolation changes the relative root scale. Storage is never redistributed. Files may also recede by indexed size; grouped remainder geometry is not counted as a matching folder.
5. Focus on selection emphasizes its real ancestors and descendants. Show Path to Root emphasizes only the selected node and ancestors. Unrelated branches/labels recede to about 20%. Size hide rules still apply; selected/context chains stay recognizable. Focus follows the shared selection.
6. Resolve labels and hits from the resulting visibility. Hidden nodes have no labels/hits/keyboard targets. Emphasized discs/labels win overlaps before faded discs. Faded discs remain directly selectable; their labels do not steal hits from emphasized content. Selecting one updates shared focus predictably.
7. Render using the existing radial painter, category palette, size scale and camera.

Counts describe real descendant folders placed in the current bounded depth/per-folder layout, including a retained selection chain beyond those limits: root, files, grouped remainders, rings and decorative marks are excluded. Show visible folders / available folders, threshold matches and extra contextual ancestors/selection exceptions separately. Dim counts the faded folders as visible; Hide counts only matches plus required context. These counts do not imply all catalog folders were loaded. No-match explanations retain navigation context and offer All/reset. All never reports a below-filter exception. Positive thresholds distinguish a selected group (navigation context), an unknown indexed size, and a known size below the threshold.

Isolation changes only the visual root and shared selection, not inventory data. Enter selects its folder and remembers the pre-isolation selection; nested isolation keeps that original selection. The active visual root cannot be redundantly isolated. Exit/reset restores the entry selection and its Navigator ancestor expansions/scroll route. Up walks real parents back toward the browser root. Selecting outside isolation or changing the browser folder exits isolation without overriding the new user selection. Unloaded descendants are explained. Size/focus settings and visual re-rooting have no catalog reader. Selecting a previously unexpanded path can use the Navigator's existing bounded catalog-page reads; ordinary folder exploration can load a new bounded tree. Neither is a filesystem scan.

Reset restores All, Dim, focus off and isolation off, plus the existing camera reset. It preserves Levels and restores the pre-isolation selection when applicable. No filter affects accounting, cleanup recommendations or Trash eligibility.

Size/presentation/focus changes cross-fade the existing canvas over 120 ms; Reduce Motion applies the new presentation immediately. Hidden hit targets are removed immediately. Pan/zoom and ordinary navigation keep their existing behavior. Native animation pacing and physical interaction remain pending acceptance.
